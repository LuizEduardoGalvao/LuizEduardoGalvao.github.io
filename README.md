# Loja Online - E-commerce com ASP.NET MVC e SQL Server

Este repositório contém o código-fonte de uma loja online (e-commerce) desenvolvida com o framework **ASP.NET MVC**. O objetivo do projeto é criar uma aplicação funcional que inclui autenticação de usuários, gerenciamento de produtos e integração com banco de dados **SQL Server**.

---

## 📋 Funcionalidades
- 🛒 **Página inicial** com listagem de produtos armazenados no banco de dados.
- 🔍 **Detalhes dos produtos** com informações detalhadas para os usuários.
- 🔐 **Sistema de login e registro de usuários** com autenticação segura.
- 🛍️ **Carrinho de compras** para adicionar e remover produtos.
- 🗃️ **Integração com SQL Server** para gerenciamento de dados.
- 📧 **Formulário de contato** para envio de mensagens.

---

## 🛠️ Tecnologias Utilizadas
O projeto foi desenvolvido com as seguintes tecnologias:
- **ASP.NET MVC 5**: Framework para desenvolvimento de aplicações web em C#.
- **C#**: Linguagem de programação principal.
- **Entity Framework**: ORM para interação com o banco de dados.
- **SQL Server**: Banco de dados para armazenar produtos, usuários e pedidos.
- **HTML5**, **CSS3** e **JavaScript**: Para a interface do usuário.
- **Bootstrap**: Para design responsivo.
- **Git** e **GitHub**: Controle de versão e hospedagem do código.
